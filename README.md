# DSA Practice
A collection of Data Structures and Algorithms problems I solve while preparing for software engineering interviews.

Goals
- Strengthen problem-solving skills.
- Understand common data structures and algorithms.
- Compare different approaches to the same problem.
- Analyze time and space complexity.
- Improve code readability and problem-solving explanations.

Topics Covered
- Arrays
- Strings
- Hash Maps
- Set
- Other topics as I progress

Languages
- JavaScript

Learning Approach
For each problem, I aim to understand the problem, develop an initial solution, explore possible optimizations and document the complexity and key learnings.
This repository is a work in progress and will grow as I practice more problems.
